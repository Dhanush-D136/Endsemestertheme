# End Semester Practical Examination Frontend

An interactive, responsive theme-based presentation and dashboard system for End Semester Practical Examinations.

## Features
- **Dynamic Interactive Themes**:
  - Theme A: Pond, water waves, floating lotuses, and animated dual waterfalls
  - Theme B: Beach scene with sky, animated sun, clouds, flying gulls, sailing boat, ocean waves, tides, crabs, and turtle
  - Theme C: Forest scene with animated wildlife, swaying trees, pond with ducks, and night fireflies
- **Live Synchronized System Clock**: Precision date and 12-hour format Indian Standard Time display
- **Day / Night Lighting Cycle**: Dynamic solar and lunar positioning with gradual sky gradient shifts
- **In-Browser Layout Customization**: Editable layout blocks, custom text/card sizes, and custom image uploads saved locally
- **Zero-Dependency Static Architecture**: Pure HTML5, CSS3 animations, and vanilla JavaScript with embedded SVG and Base64 assets

## Deployment on Vercel
This project is configured for instant zero-configuration deployment on [Vercel](https://vercel.com):
- Entry point: `index.html`
- Configuration: `vercel.json` with clean URLs and fallback rewrites

Every commit pushed to the `main` branch automatically triggers a production deployment on Vercel.
